# zettle-mcp

This project builds an mcp server around a markdown repository. This is in support of AI assistants that need to interact with these repositoties programatically. This project will also build out any other code or resources needed to feed the 


## Capabilities under consideration are:

- Ability to programatically read and write to markdown files in the source repository.
- Ability to manually edit markdown files in the source repository.
- Ability to search the repository for relevent information.
- Ability to supliment LLM calls to reduce token usage.
- Ability to integrate with both raw markdown files and an Obsidian repository.
- Ability to interact with and maintain frontmatter standards in the repositiry.
